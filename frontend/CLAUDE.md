# CLAUDE.md — frontend/

## 役割
ユーザーが触れるUI。純粋なHTML/CSS/Vanilla JSのみ。フレームワーク禁止。

## デザイン原則
- ダークテーマ（ネイビー×サイバーブルー）を維持
- フォント: Google Fonts（Bebas Neue / Noto Sans JP / JetBrains Mono）
- portfolio_hoshino_jaewon.html のデザインが品質基準

## 画面構成
- `index.html`   : ファイルアップロード + 説明
- `preview.html` : 生成結果プレビュー（ウォーターマーク付）+ 500円決済ボタン

## 禁止事項
- React / Vue / jQuery などフレームワーク・ライブラリ禁止
- インラインスタイルは最小限に
- 外部CDNはGoogle Fonts以外禁止
